# Антикризисный штаб – лендинг Алексея Урванцева

Статический сайт без сборки: открывается двойным кликом по `index.html`, публикуется на GitHub Pages.

## Как опубликовать на GitHub

1. Создайте репозиторий, загрузите в корень всё содержимое этой папки (`index.html`, `css`, `js`, `img`, `README.md`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
4. Свой домен: в том же разделе Pages поле Custom domain. Для кириллического домена нужна punycode-запись (`xn--...`), её даёт регистратор.

Папку `img/` не переименовывайте: пути к фото, письмам и логотипам прописаны в `index.html`.

## Что заполнить перед запуском рекламы

Все настройки в начале `js/main.js`, объект `CONFIG`:

| Поле | Что это |
|---|---|
| `FORM_ENDPOINT` | Адрес приёма заявок. GitHub Pages сам заявки не принимает. Подойдёт Formspree, Getform или свой сервер. Форма отправляет JSON со всеми полями, включая UTM, `erid`, `headline_variant`, `form_position`. Пока поле пустое, форма честно пишет, что не подключена. |
| `YM_ID` | Номер счётчика Яндекс.Метрики. После отправки формы фиксируется цель `lead`. |
| `VK_PIXEL_ID` | Номер пикселя VK Реклама. Цель `lead` отправляется так же. |
| `POLICY_URL`, `REQS_URL` | Ссылки на политику обработки персональных данных и реквизиты ИП. Пока `#`. |

Цели в Метрике и VK нужно создать самим (идентификатор цели `lead`) и проверить, что она срабатывает при реальной отправке.

## Тесты и метки

- Заголовок: `?h=a` («боль») и `?h=b` («механика»); без параметра – основной. Значение уходит в заявку как `headline_variant`.
- Метки `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `erid` берутся из адреса страницы и уходят в скрытые поля.
- Позиция формы (`form_position`): `mid` (после возражения), `final` (внизу), `popup` (кнопки «Обсудить ситуацию»).

## Что нужно решить (я не мог решить за вас)

1. **Цена.** Актуальные цены (подтверждены): диагностика 250 000 ₽, день сессии 250 000 ₽, трекинг внедрения 250 000 ₽ за 8 часов. Они в ответе FAQ «Сколько стоит» (`index.html`, блок `#faq`).
2. **Логотипы клиентов** (`img/clients.jpg`) взяты из вашей презентации. Нужно согласие компаний на публикацию.
3. **Письма-благодарности** (`img/letters/`) показываются в карточках кейсов. В письме «Активити Групп» я закрыл банковские реквизиты, остальные обрезаны по тексту письма. Убедитесь, что клиенты не против публикации.
4. **Письма по Уфаойл и «Авитек».** Их нет в загруженных материалах, поэтому у этих двух кейсов письма не показаны. Раньше в тексте стояла фраза «по каждому кейсу есть письмо». Я заменил её на «письма можно открыть в карточках», чтобы не обещать лишнего.
5. **Регалии.** В блоке «Кто ведёт» четыре пункта подписи из брифа маркетологу, дословно и в том же порядке. Пункты «Элита менеджмента» и «ТОП-10 по лидерству» из текста v2 в блок не вошли. Регалию HRTime.ru нигде не использовал.
6. **Согласие на обработку данных.** В нижней и всплывающей формах – чекбокс, в форме посередине – строка под кнопкой. Подтвердите с юристом, что так допустимо по 152-ФЗ.
7. **Cookie-баннер.** Если подключаете Вебвизор Метрики, юрист может потребовать баннер. В сайт он не заложен.
8. **Формат при невозможности двух дней подряд.** В FAQ обещано «разносим по графику». Подтвердите, что это так.

## Что намеренно не включено

- Цифры рынка (ключевая ставка, НДС, доля МСП) из брифа: там стоит условие перепроверять их перед публикацией. Добавляйте только после проверки.
- Статистика закрытий компаний: нет первоисточника.
- Видеоотзывы: материалов нет. Если снимете, блок можно сделать по образцу карточек кейсов.

## Доступность и телефоны

Фокус с клавиатуры виден, вкладки управляются стрелками, анимации отключаются настройкой «уменьшить движение». На телефоне: липкая кнопка внизу экрана, поля ввода 16 px (без автозума iOS), слайдер кейсов листается пальцем, полотно логотипов листается в сторону.

Шрифт Onest подключается с Google Fonts. Если нужен автономный сайт, скачайте шрифт в `fonts/` и подключите через `@font-face`.
