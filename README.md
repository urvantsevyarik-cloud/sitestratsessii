# urvancev-ux

Самостоятельная страница «Антикризисная стратегическая сессия» для GitHub Pages. Мобильная версия — основная.

## Структура

```
index.html          страница (весь текст, форма)
css/style.css       вёрстка: мобильная первым делом, затем планшет и компьютер
css/urvancev.css    Montserrat, переносы, абзацы, нижняя панель на телефоне
js/urvancev.js      неразрывные пробелы после предлогов, абзацы, нижняя панель
js/page.js          форма заявки
```

`index.html` должен лежать в корне репозитория, рядом с папками `css` и `js`.

## Публикация

Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
Через минуту страница откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`. После этого `README.md` на странице больше не показывается.

## Что настроено

- Шрифт Montserrat, заголовки Bold (700), жирный в тексте 600.
- Висячие предлоги, союзы и частицы, тире, числа, телефон, инициалы: неразрывный пробел расставляется скриптом при загрузке. Последние два слова абзаца не разрываются.
- Абзацы: один отступ между абзацами, строки не длиннее 68 символов, жирные заходы («Кризис называем вслух.») идут отдельной строкой.
- Телефон: текст 16 px, кнопки и поля от 48 px, нижняя панель «Обсудить ситуацию» и звонок (появляется после первого экрана, исчезает у формы и при открытой клавиатуре), вопросы раскрываются по нажатию.

## Форма заявки

GitHub Pages не принимает данные, поэтому есть два режима:

1. **Сейчас:** при отправке открывается письмо на `mail@urvancev.info` с заполненным текстом.
2. **Лучше:** заведите форму на Formspree или аналоге и вставьте её адрес в `index.html`: `<form id="lead-form" data-endpoint="https://formspree.io/f/XXXX">`. Тогда заявки будут приходить без почтовой программы.

## Что поменять под себя

- Цвета: переменные `--accent`, `--ink`, `--soft` в начале `css/style.css`. Это рабочая палитра, фирменные цвета с исходного сайта я не видел.
- Telegram: на старой странице два разных ника (`Alexey_Urvancev` и `AlexeyUrvancev`). В `index.html` стоит первый, отметка `TODO` рядом.
- Отключить обработку текста в блоке: атрибут `data-no-typo`. Оставить конкретный перенос строки: атрибут `data-keep` на теге `<br>`.

## Не перенесено

Тексты благодарственных писем (ООО «Лаконд», «МЦ-Сервис Инжиниринг») и бегущая строка в шапке. Письма логично добавить как отдельные файлы или раскрывающиеся блоки, когда будут готовы сканы или согласие клиентов на публикацию.
